# E-commerce – Clothing shop

A small React app showing the shop's product categories (hats, jackets, sneakers, womens, mens).

## Run locally

```bash
cd app-clothing
npm install
npm start
```

## Live site

Every push to `main` builds the app and publishes it to GitHub Pages through
`.github/workflows/deploy.yml`. The site is at
`https://<your-username>.github.io/<repo-name>/`.
